# Hi, I'm Andrei Manoloiu

**Data Analyst at [LEGO Group](https://www.lego.com)** · BSc Cybernetics · MSc Data Science (SDU) · Kolding, Denmark

I work on **econometrics, causal inference and machine learning**, mostly on EU regional and macro data. My projects are end-to-end: data ingestion, modelling, and an interactive front end to explore the results.

## Featured projects

| Project | What it does | Stack |
|---|---|---|
| [**rd-productivity-eu**](https://github.com/andrm101/rd-productivity-eu) | Panel econometrics of R&D and productivity across 29 European countries, 1998–2024: GMM/IV, spatial spillovers, local projections, causal forests. Extends my bachelor's thesis. | Python, R, DuckDB |
| [**pl-capital-reform-did**](https://github.com/andrm101/pl-capital-reform-did) | Causal analysis of Poland's 1999 reform that demoted 31 cities from province capitals. Triangulated with 6 estimators (TWFE, synthetic DiD, gsynth, local projections, panel VAR, ARIMA). Synthetic DiD estimates a ~4.5% population loss versus the synthetic control. | Python, R |
| [**eu-gnn-risk-monitor**](https://github.com/andrm101/eu-gnn-risk-monitor) | Graph neural network autoencoder that scores economic and political anomalies across EU NUTS2 regions. It recovers the 2020 COVID shock without being told when it happened. | Python, PyTorch, React |

| [**thesis-interface-build**](https://github.com/andrm101/thesis-interface-build) | Desktop app reproducing my bachelor's thesis: augmented Solow model, K-Means typology, FE/RE with Hausman, unit-root tests, and causal designs. | Python, Tkinter, matplotlib |
| [**project-for-data-modelling**](https://github.com/andrm101/project-for-data-modelling) | Comparison of KMeans, GMM and hierarchical clustering with silhouette, ARI and stability analysis. Initialization mattered more than algorithm choice. | Python, scikit-learn |
